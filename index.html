Research

I am interested in AI security and adversarial robustness for both discriminative and generative models. My research develops scalable adversarial attacks, defenses, and evaluation frameworks. Recent projects explore multi-label adversarial attacks and backdoor attacks in diffusion models.

Compositional Targeted Multi-Label Universal Perturbations
Hassan Mahmood, Ehsan Elhamifar
CVPR, 2025
Spotlight Presentation at UNCV Workshop 2025
Paper / Code

Learning a single universal perturbation that can simultaneously target multiple labels in multi-label classification models by composing label-specific perturbations.

Semantic-Aware Multi-Label Adversarial Attacks
Hassan Mahmood, Ehsan Elhamifar
CVPR, 2024
Paper / Code

Generating multi-label adversarial examples that respect the semantic relationships between labels, leading to more realistic and effective attacks.

Rethinking Table Recognition using Graph Neural Networks
Shah Rukh Qasim, Hassan Mahmood, Faisal Shafait
ICDAR, 2019
Paper / Code

A novel graph neural network-based approach for table structure recognition in document images, improving accuracy and robustness over traditional methods.
