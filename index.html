Research

I am interested in AI security and adversarial robustness for both discriminative and generative models. My research develops scalable adversarial attacks, defenses, and evaluation frameworks. Recent projects explore multi-label adversarial attacks and backdoor attacks in diffusion models.

Publications

 Compositional Targeted Multi-Label Universal Perturbations Hassan Mahmood, Ehsan Elhamifar
CVPR, 2025
Spotlight Presentation at UNCV Workshop 2025
Paper / Code

A scalable approach to generate targeted multi-label universal adversarial perturbations through a compositional framework, reducing time and space complexity from exponential to linear while retaining strong attack effectiveness.

Semantic-Aware Multi-Label Adversarial Attacks Hassan Mahmood, Ehsan Elhamifar
CVPR, 2024
Paper / Code

A knowledge-graph based framework to generate semantically aware adversarial attacks for multi-label learning and addressed the negative gradient correlation in perturbation optimization, enabling effective attacks, scalable to large datasets.

Rethinking Table Recognition using Graph Neural Networks Shah Rukh Qasim, Hassan Mahmood, Faisal Shafait
ICDAR, 2019
Paper / Code

A graph neural network based approach that models spatial relationships between table elements to accurately recognize table structures in document images, robust to complex and irregular layouts.
